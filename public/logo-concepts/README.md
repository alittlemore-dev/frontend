# Logo concepts

Exploratory logo marks generated for comparison. These source files are not wired into the site directly; selected marks are exported to the production favicon and logo assets.

## Selected marks

- `01-alm-continuous-growth.png` is retained only as the original full-size concept.
- `05-competency-path.png` is the source for the favicon, Apple Touch, and Android Chrome icon families, as well as the public navbar, the site-build case study, and repository README branding.

Production derivatives live at the root of `frontend/public/`; keep these source concepts unchanged when regenerating output sizes.

- `01-alm-continuous-growth.png` — continuous ALM ribbon and upward progression
- `02-alm-modular-step.png` — modular ALM monogram
- `03-code-growth.png` — code brackets with an incremental growth path
- `04-open-knowledge.png` — code brackets, opening knowledge, and an upward spark
- `05-competency-path.png` — modular competency path ending in a code-shaped tile
